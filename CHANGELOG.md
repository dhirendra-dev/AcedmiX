# Changelog

## 1.1.0 — Study studio expansion

- Added a daily study planner with task creation, subject labels, completion, deletion, and local persistence.
- Added a focus timer with 25/5/15-minute presets, pause/resume, reset, completion feedback, and session counting.
- Added saved-course bookmarking and a saved-only library filter.
- Added a persistent editorial dark appearance option.
- Added `Ctrl/⌘ + K` library search shortcut and `Escape` mobile-menu dismissal.
- Expanded responsive navigation to include Planner and Focus.
- Documented local-only persistence and new interaction patterns.


## 1.2.0 — Practice Studio

- Added a mixed-subject five-question quiz.
- Added answer selection, completion validation, instant explanations, and score feedback.
- Persisted the learner's best quiz percentage locally.
- Added responsive editorial quiz cards and dark-theme states.


## 1.3.0 — Learning desk

- Added searchable subject-tagged study notes with local persistence and deletion.
- Added flashcard creation, answer reveal, and previous/next active-recall review.
- Added responsive light and dark styling for the learning desk.
- Clarified that notes and flashcards are stored only in the current browser.
